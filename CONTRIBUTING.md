# Contributing

Use the [authoring guide](docs/authoring.md). For a new skill, add its folder under `skills/`, update `catalog.json` and the router's reference, and add a scenario under `eval/scenarios/`. Cite the official versioned sources and describe how you checked version-sensitive claims.

Run the checks in the [README](README.md). For changes to Moodle guidance, include the scenario results and identify the Moodle branch, agent, and checks you used. For gaps or incorrect instructions, identify the skill, branch, expected behavior and official reference.
