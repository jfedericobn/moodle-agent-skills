# Sources and reuse

Each skill and its catalog record link to official developer resources. Moodle release branches and representative core components help verify version-sensitive claims. The pilot guidance was written for this repository.

- [WordPress Agent Skills at 7374e6f](https://github.com/WordPress/agent-skills/tree/7374e6f) informed structure, routing, installer and scenario design.
- [claude-moodle-dev at 18bf118](https://github.com/SaadRahman01/claude-moodle-dev/tree/18bf118) informed workflow coverage. Its commands and examples need per-branch verification before adoption.
- [Moodle peer review helper](https://github.com/lameze/moodle-skills/tree/854b65e), [Moodle Playground Agent Skills](https://github.com/WisdmLabs/moodle-playground/tree/ff158d3/packages/agent-skills), [MoodlIA Skills](https://github.com/gafapa/moodlia-skills/tree/b3c1f50), and [Laravel Boost](https://github.com/laravel/boost/tree/6004f09) were assessed for adjacent scope, installation and evaluation ideas.

When importing material in a future change, identify the exact source and revision, determine the file's license, retain attribution and notices, and record how the imported guidance was checked. Moodle documents its licensing on the [Developer Resources license page](https://moodledev.io/general/license).
